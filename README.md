# SDLC in the Age of AI

A walkthrough of the Software Development Life Cycle, plus a hands-on exercise using AI to draft and refine agile artifacts.

## Contents
- SDLC diagram and explanation of all six phases: Requirement, Design, Development, Testing, Deployment, Maintenance
- AI-generated user stories for an e-commerce application
- Acceptance criteria (Given-When-Then) for the payment user story
- Sprint backlog with tasks, priorities, and story points
- Manual review of the AI output and notes on why human review still matters
